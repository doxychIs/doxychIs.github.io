# Портфолио dox

Сайт: https://doxychis.github.io/

## Главная dox.

Монохромное портфолио без сборщика и сторонних библиотек: HTML, CSS и модули JavaScript. Локальные шрифты Golos Text; лицензия в `assets/dox/fonts/OFL.txt`.

Из корня репозитория запустите `python -m http.server 8080`, затем откройте http://localhost:8080/. Проверки: `npm run check` (Node.js 22+; установка зависимостей не нужна).

Главная страница — `index.html`, стили и взаимодействия — `assets/dox/`. Белые кривые реагируют на мышь и касание, меняют форму и при прокрутке собираются в `dox.`. Кнопка «Рассыпать» повторяет анимацию. Движение можно выключить; системное ограничение анимации учитывается, выбор сохраняется локально. В скрытой вкладке анимация приостанавливается. Без JavaScript остаются все проекты и статичная подпись. Превью на телефонах видны постоянно, на компьютере раскрываются при наведении и фокусе с клавиатуры.

Для публикации достаточно отправить изменения в `main`: готовые файлы обслуживаются GitHub Pages напрямую.

- `/` — портфолио.
- `/aura/` — статическая сборка сайта AURA с Ритуалом AURA.
- `/86-ceh/` — браузерная игра в разработке, обычный режим без SDK Яндекс Игр.
- `/smena/` — студия волос СМЕНА: коллекция образов и конструктор визита.
- `/tish/` — пространство ухода ТИШЬ: маршруты и интерактивная минута тишины.
- `projects/smena/`, `projects/tish/` — полные независимые исходники Astro/TypeScript.
- `docs/profile-README.md` — текст для профиля GitHub; его нужно разместить в README.md публичного репозитория doxychIs/doxychIs.

Публикуется ветка main, папка / (root). Сборка на GitHub не нужна. AURA опубликована из готовой сборки последнего архива; пути адаптированы для /aura/. Оригинальные исходники остаются в исходном архиве. Контакты салона не заполнены; форма подготавливает детали визита в браузере.

## СМЕНА и ТИШЬ

Оба проекта публикуются из готовых сборок в корневых папках `smena/` и `tish/`. Исходники сохранены отдельно в `projects/`; там находятся данные бизнеса, инструкции, тесты и лицензии шрифтов. Фактические контакты и юридические данные не придуманы, формы составляют только локальный план.

Для обновления проекта (Node.js 22.12+):

```bash
cd projects/smena
npm ci
npm run build
npm test
```

Скопируйте содержимое `projects/smena/dist/` в `smena/` и отправьте изменения в `main`. Для ТИШИ аналогично используйте `tish`. Префиксы публикации заданы в `business.config.json`; все страницы, изображения, шрифты и внутренняя навигация учитывают их.
