# Портфолио dox

Стартовая страница личного портфолио: сайты, браузерные игры и эксперименты.

## Публикация

1. Откройте Settings → Pages.
2. В разделе Build and deployment выберите Source: Deploy from a branch.
3. Выберите ветку main, папку / (root) и нажмите Save.
4. Дождитесь завершения публикации. Адрес: https://doxychis.github.io/

## Файлы

- index.html — страница портфолио; стили встроены в файл.
- .nojekyll — отключает обработку файлов Jekyll.

Node.js и сборка не нужны. Для локального просмотра откройте index.html в браузере. После включения Pages изменения в main будут публиковаться автоматически.

## Проекты

AURA и «86 ЦЕХ» представлены как готовящиеся проекты. Их исходники в этот репозиторий не загружены. Ссылки на работающие версии следует добавлять после публикации отдельных проектов.
