# ТИШЬ

Самостоятельный портфолио-проект российского бьюти-бизнеса в Перми. Бренд, редакционные тексты и цены придуманы для проекта; они не представляют существующую компанию. В интерфейсе нет вымышленных отзывов, рейтингов или юридических реквизитов.

## Концепция

Камерное пространство ухода: приглушённый розовый, сливовый, мягкий свет, натуральные материалы, Prata и Noto Sans. Посетитель выбирает цельный маршрут, а не собирает корзину процедур.

«Минута тишины»: управляемая пауза с шестью циклами мягкого вдоха и выдоха, таймером, остановкой и продолжением. Анимация включается только по нажатию; при скрытии вкладки таймер приостанавливается. План визита показывает все этапы выбранного маршрута и учитывает предпочтения по комфорту.

## Запуск

Нужен Node.js **22.12 или новее**; проект проверен на Node.js 24.19.

```bash
npm ci
npm run dev
```

Откройте **http://localhost:4322/tish/**. Проекты используют разные порты, поэтому их можно запускать одновременно.

```bash
npm run build
npm test
npm run preview
```

`build` сначала проверяет TypeScript и Astro, затем создаёт статический сайт в `dist/`. `test` проверяет расчёты, клиентские сценарии и все страницы собранного сайта; перед тестами нужна сборка. После сборки `dist/` можно скопировать в папку `tish/` в корне репозитория портфолио. `preview` показывает production-сборку на том же порту.

Для публикации в подпути используется `basePath` в конфигурации; все внутренние ссылки и ресурсы учитывают этот префикс.

Не открывайте HTML двойным щелчком через `file://`: для переходов между страницами нужен HTTP-сервер.

## Структура

- `src/pages/` — страницы и динамические статические маршруты.
- `src/layouts/` — метаданные, локальные шрифты и оболочка.
- `src/components/` — компоненты именно этого бренда.
- `src/data/care.ts` — услуги, цены и сценарии.
- `src/scripts/` — независимый клиентский TypeScript.
- `src/styles/site.css` — визуальная система и адаптивные состояния.
- `public/images/` — оптимизированные локальные изображения.
- `business.config.json` — данные бизнеса для замены.
- `tests/` — автоматические проверки.
- `LICENSES/` — лицензии шрифтов.

Страницы: Главная; каталог маршрутов и меню ухода; четыре подробных маршрута; пространство; план визита; конфиденциальность; 404.

## Данные бизнеса

В `business.config.json` централизованы название, город, адрес, часы, телефон, почта, домен и ссылка реального сервиса записи. Отсутствующие контактные и юридические сведения оставлены пустыми. Пустые телефон, адрес и почта не выводятся на сайте.

Перед передачей реальному салону заполните `siteUrl`, контакты, `bookingUrl` и данные оператора в `legal`; проверьте фактические цены, расписание и текст конфиденциальности. Без `siteUrl` не создаётся вымышленный canonical-домен. После изменения конфигурации выполните `npm run build`.

## Формы и данные

Backend отсутствует. Формы не отправляют заявки, не подтверждают время и не сохраняют пожелания в cookie или localStorage. Они создают текстовый план в текущей странице и по запросу скачивают `.txt`. Это явно объясняется рядом с формой и в результате. Пользовательский текст выводится через `textContent`. Без JavaScript отправка заблокирована; основной контент и навигация остаются доступны.

Если указан `bookingUrl`, в готовом плане появится отдельная ссылка на реальный сервис записи. Внешняя запись не имитируется.

## Доступность и размещение

Есть русские подписи, alt-тексты, переход к содержимому, клавиатурные состояния, Escape для меню, нативные поля и раскрывающиеся блоки, сообщения через live regions. Учитывается `prefers-reduced-motion`. Все изображения и шрифты локальные, внешняя аналитика не подключена.

Можно разместить содержимое `dist/` на статическом хостинге в подпути из `basePath`. Для размещения в корне измените `basePath` на `/` и пересоберите. Сохраняйте вложенные каталоги с `index.html`, настройте страницу ошибки на `404.html`. Проект не требует сервера Astro после сборки.

Подробнее об изображениях — в `ASSETS.md`, о выполненных проверках — в `VERIFICATION.md`.
