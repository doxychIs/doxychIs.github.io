# Фоны и читаемость 3.1

Шесть фонов созданы встроенным генератором изображений как отдельные широкие сцены. Фактическое разрешение каждого исходника — 1672×941. Файлы сохранены без увеличения разрешения в WebP с качеством 96 и используются из `assets/locations/`. Это полноценные сцены, а не растянутые фрагменты одного атласа. Мини-портреты команды из версии 3.0 сохранены.

Тёмные подложки заголовков имеют непрозрачность 84%, светлые панели — 95–97%. Размытие применяется к подложке под интерфейсом, фоновые изображения не размываются программно. Настройки компактного экрана находятся в `focus.css`.
