# Персонажи и графика «86 ЦЕХ»

Для команды выбраны главные герои и их ближайшие спутники. Мини-портреты — новые стилизованные иллюстрации; игровые роли и бонусы придуманы для тайкуна. Роботы и их модульные формы остаются оригинальными.

Референсы: [список персонажей на вики](https://86-eighty-six.fandom.com/wiki/Characters), [официальная галерея первой части](https://anime-86.com/character/first-half/), [галерея второй части](https://anime-86.com/character/second-half/). Вики использована для имён и описаний, официальная галерея — для проверки внешности.

| Герой | Отличительные черты мини-версии |
| --- | --- |
| Шинэй Нодзэн — Шин | Чёрные волосы, красные глаза, светлый шарф, книга |
| Владилена Милизе — Лена | Длинные серебристые волосы, синяя форма и фуражка |
| Райден Шуга | Волосы торчком, крепкий силуэт, ключ на плече |
| Теото Рикка — Тео | Золотистые волосы, зелёные глаза, альбом для рисования |
| Андзю Эмма | Длинные серебристо-голубые волосы, спокойная поза |
| Курэна Кукумила | Короткое каштановое каре, золотистые глаза, энергичная поза |
| Фредерика Розенфорт | Чёрные волосы, красные глаза и бант, бордовое платье |

Мини-портреты подготовлены встроенным генератором изображений и разделены на семь прозрачных WebP в `assets/characters/`. В версии 3.1 все шесть фонов заменены отдельными широкими изображениями: [новые фоны и запросы](ФОНЫ-3.1.md). Внешних загрузок графики во время игры нет. SVG-модули роботов создаёт `src/robot-view.js`, без 3D-библиотек.

## Запрос для атласа команды

Создай ЕДИНЫЙ прозрачный атлас игровых мини-персонажей чиби из аниме «Восемьдесят шесть». Ровно 8 ячеек в строгой сетке 4 столбца × 2 строки, 2048×1536, одинаковое центрирование и масштаб, каждый герой целиком виден с запасом до края своей ячейки, нигде не касается соседей. Верхний ряд слева направо: 1 Шинэй Нодзэн / Шин: юноша, чёрные взъерошенные волосы с чёлкой, красные глаза, светло-голубой шарф, коричневая полевая куртка, спокойная улыбка, держит книгу; 2 Владилена Милизе / Лена: девушка с очень длинными серебристыми волосами и двойным ахоге, серебристые глаза, синяя фуражка с белыми деталями, синяя приталенная форма с белыми манжетами и юбкой, чёрные колготки, дружелюбно машет; 3 Райден Шуга: высокий крепкий юноша в чиби пропорциях, короткие тёмно-зелёные волосы торчком, зелёные глаза, коричневая полевая куртка, держит гаечный ключ на плече, уверенный; 4 Теото Рикка / Тео: невысокий стройный мальчик с растрёпанными золотистыми волосами и зелёными глазами, коричневая куртка с чёрной высокой горловиной, рисует в альбоме. Нижний ряд: 5 Андзю Эмма: девушка с длинными прямыми серебристо-голубыми волосами и голубыми глазами, коричневая куртка, мягкая улыбка, держит маленькую шестерёнку; 6 Курэна Кукумила: девушка с коротким каштаново-рыжим каре, золотистыми глазами, коричневая куртка, энергичная поза с поднятым кулачком; 7 Фредерика Розенфорт: маленькая девочка с длинными чёрными волосами, красными глазами, красным большим бантом, бордовое платье с белой оборкой, тёмные чулки, смешная гордая поза с руками на поясе; 8 ячейка полностью ПУСТАЯ и прозрачная. Стиль: качественная рисованная аниме чиби фигурка 2.5 головы роста, крупные выразительные глаза, очень разные силуэты волос, позы и костюмы; дружелюбная приключенческая игра для детей. Без оружия, текста, подписей, рамок, эмблем, фона, теней фона. Настоящая прозрачность альфа-канала.
