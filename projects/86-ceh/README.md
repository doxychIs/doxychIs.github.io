# 86 ЦЕХ — мир изобретателей 3.1

Браузерный тайкун: стройте фабрику, собирайте DOX, находите детали, создавайте роботов и побеждайте соседние мастерские. Фан-проект с мини-персонажами «Восемьдесяти шести». HTML, CSS и обычный JavaScript; зависимостей нет.

## Запуск в VS Code

1. Распакуйте архив и откройте папку `ceh` в VS Code.
2. Установите Node.js 18 или новее, если его ещё нет.
3. В терминале выполните `npm run dev` и откройте http://localhost:5173.

Альтернативы: расширение Live Server или `python -m http.server 5173`. Игра требует локального HTTP-сервера. Сервер останавливается сочетанием Ctrl+C.

Новая версия узнаётся сразу: название **«86 ЦЕХ»**, отметка **3.1**, цветной гараж и панель перемещения снизу. В центре — кликер; деньги и пассивный доход находятся сверху. Кнопки «Строить», «Улучшения» и «Мой путь» открывают подробности поверх сцены. Если открылась прежняя версия, остановите старый сервер, запустите его из новой папки и обновите страницу Ctrl+F5. Сбрасывать прогресс не требуется. Для переноса локального сохранения используйте прежний адрес и порт.

## Как играть

Нажимайте на робота, кнопку «Собрать DOX» или Пробел. Покупайте рабочих, станки, конвейеры и улучшения. После 25 нажатий или 90 заработанных DOX откроются мастерская и шесть стартовых деталей. Первый робот доступен без персонажей и случайной удачи.

В робомастерской нажмите «Собрать автоматически» и посетите арену. Бой длится 10–20 секунд: робот атакует сам, вы включаете щит и перегрузку. Награды улучшают производство и сборку. Новая эпоха требует капитала и победы над боссом. Дубликаты деталей разбираются или объединяются, четыре детали одного комплекта дают особый эффект.

Крафт позволяет выбрать слот, **форму** и качество детали. В каждой эпохе есть три разных модели головы, корпуса, каждого оружия, ходовой и ядра. Всего 133 определения деталей, включая семь особых ядер боссов. Меняются и вид, и характеристики.

Из яиц появляются Тео, Райден, Курэна, Андзю, Лена, Шин и Фредерика. Назначенные пилот и инженер одновременно усиливают цех, нажатия и робота. Бои дают опыт, дубликаты — фрагменты. Все семь мини-портретов видны в коллекции, даже до знакомства.

Разделы находятся в разных локациях: гараж, ангар, комната команды, арена и сад достижений. Позднее открывается космическая верфь. Перемещение меняет сцену внутри игры; производство продолжается. Склад, крафт, характеристики робота, бонусы персонажей и магазин наград раскрываются отдельно. Кнопка «?» объясняет выбранную локацию. В настройках можно убрать звуки и активные анимации.

## Сборка

| Команда | Результат |
| --- | --- |
| `npm run build` | Обычная статическая версия в `dist/` |
| `npm run build:yandex` | Версия для Яндекс Игр в `dist/` |
| `npm run preview` | Локальный просмотр `dist/` |
| `npm run check` | Короткая проверка кода, экономики, сохранений и обновления |
| `npm test` | Все проверки, включая несколько коротких боёв |

В архиве уже есть `dist/` и **`yandex-games.zip`**. Для Яндекс Игр загрузите последний: `index.html` находится в его корне. После изменения проекта выполните `npm run build:yandex` и заархивируйте содержимое `dist/`, без внешней папки. Для обычного хостинга — `npm run build`.

## Сохранения и устройство

Автосохранение каждые 15 секунд и после важных действий, резервная копия, офлайн-доход до восьми часов, материалы и ящики за отсутствие. Сброс требует подтверждения. Формат сохранения остаётся 2, ключ `ceh.save.v1` сохранён. Версии 1 и 2 переносятся; старые помощники превращаются в новую команду с сохранением уровней, опыта, развития, ролей и яиц.

`src/config.js` — экономика. `src/expansion-config.js` — детали, формы, персонажи, рецепты, противники, выпадения и награды. `src/locations.js` — локации и переходы. `src/robot-view.js` — модульная 2.5D-графика. `game.css` — игровое оформление, `focus.css` — компактный экран и контрастные подложки. `src/help.js` — короткие объяснения для кнопки «?». Подробности: [баланс](docs/БАЛАНС.md), [персонажи и графика](docs/ПЕРСОНАЖИ-И-ГРАФИКА.md).

`src/platform.js` изолирует Яндекс SDK, готовность загрузки, облачные данные и рекламу. Локальная версия работает без SDK. Облако выключено в `CONFIG.platform.cloudSaves`, реклама не запускается автоматически. Внешнего сервера и настоящего мультиплеера нет.

Проверки экономики, миграций, крафта и коротких боёв выполнены. Отдельно проверены обработчики кнопок открытия подробностей, покупок и клика. Изображения и модульные роботы проверены отдельно. Браузерная проверка в этой среде недоступна; перед публикацией проверьте интерфейс на устройствах и настоящий SDK в черновике Яндекс Игр.
