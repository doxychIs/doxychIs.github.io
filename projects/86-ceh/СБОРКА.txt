86 ЦЕХ — МИР ИЗОБРЕТАТЕЛЕЙ
Версия приложения: 3.1.0
Версия сохранения: 2, совместима с прежними версиями 1 и 2.

6 отдельных широких фонов 1672×941 без нарезки из атласа: гараж, ангар, комната команды, арена, сад, космическая верфь.
7 мини-персонажей: Шин, Лена, Райден, Тео, Андзю, Курэна, Фредерика.
133 определения деталей: три модели каждого слота в семи эпохах и семь ядер боссов.
Компактная главная сцена: деньги, пассивный доход, робот-кликер и три кнопки действий.
Фабрика, улучшения и путь открываются в окнах. Остальные подробности свёрнуты.
Текст защищён полупрозрачными подложками, механики и сохранения сохранены.

Запуск из новой папки ceh: npm run dev
Короткая проверка: npm run check
Все проверки с короткими боями: npm test
Для Яндекс Игр: yandex-games.zip, index.html в корне.

В игре должны быть название «86 ЦЕХ», отметка «3.1» и цветной гараж.
Перезапустите сервер из новой папки и обновите страницу Ctrl+F5.
Сбрасывать сохранение не требуется. Для сохранения прогресса используйте прежний адрес и порт.
