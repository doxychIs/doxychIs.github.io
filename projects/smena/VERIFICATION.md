# Проверка проекта СМЕНА

Проверено 7 октября 2026 года, Node.js 24.19.0.

- `npm run build`: успешная production-сборка, 10 статических страниц.
- `astro check`: без ошибок и предупреждений.
- `npm test`: 16 успешных проверок.
- Проверены все внутренние ссылки и якоря, локальные ресурсы, уникальность идентификаторов, заголовки, метаданные, alt-тексты и подписи полей.
- Клиентские сценарии проверены в изолированном DOM: переход из выбора к плану, обновление данных, защита от некорректного заполнения и безопасный вывод пользовательского текста.
- Учитываются несколько диапазонов ширины экрана и `prefers-reduced-motion`; навигация доступна без JavaScript.

Автоматические проверки DOM не измеряют визуальную верстку. Визуальная проверка в реальном браузере в текущем окружении не выполнялась: браузерный инструмент для предпросмотра недоступен. При размещении стоит просмотреть сайт на реальных телефонах и проверить подключённые фактические контакты.
